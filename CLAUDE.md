# CLM Daily

Personal daily dashboard (installable PWA) for one user. Tabs: Today, News, Vocab, Topic, Quote, Grocery, Stretch, Settings. Plain HTML/CSS/JS, **no build step and no dependencies**.

## Run and check
- `npm start` serves the site at http://localhost:5173 (or `python -m http.server 5173`).
- `npm run check` parses every JS file and validates the news brief's shape. Run it after any change to `js/`.
- Test in a browser at phone width (about 390px) and in both light and dark mode.

## Layout
| Path | What it holds |
|---|---|
| `index.html` | Shell: `<main id="app">`, bottom nav, script tags (data files load before `app.js`) |
| `css/styles.css` | All styling. Colors and fonts are CSS variables; five skins via `[data-skin]` |
| `js/app.js` | State, views, rendering, event handling |
| `js/data/words.js` | Vocabulary (`WORDS`) and difficulty lists (`LEVELS`, `LNAME`) |
| `js/data/stretches.js` | The toe-touch routine (`STRETCHES`) |
| `js/data/topics.js` | Weekly topics and lessons with knowledge checks (`TOPICS`) |
| `js/data/quotes.js` | Daily quotes with background (`QUOTES`) |
| `js/data/news.js` | The daily news brief (`NEWS`), the file that gets refreshed |
| `scripts/` | `refresh-news.js` (daily brief generator), `news-sources.json` (feeds, model, story counts), `lib/`, `check.js`, `test-refresh.js` |
| `.github/workflows/site.yml` | Daily news refresh and GitHub Pages deploy |
| `sw.js`, `manifest.webmanifest`, `icons/` | Offline cache and install-to-home-screen |

## Conventions
- Classic scripts, not ES modules, so the app also works from `file://`. Data files define globals; their order in `index.html` matters.
- **State** is one object `S` saved to `localStorage` under the key `daily.v1`. The Settings backup is this object as JSON. Never rename or remove existing fields without a migration. New fields get a default in the `S` initializer, which is merged with saved data.
- **Views** are functions that return HTML strings (`vToday`, `vNews`, `vVocab`, ...). `render()` swaps them into `#app`. Escape all dynamic text with `esc()`. Clicks are handled by one delegated listener at the bottom of `app.js` using `data-act` and `data-tab`.
- **Adding a tab:** add it to `TABS` and `ICONS`, write a `vName()` view, add it to the map in `render()`, and add it to the two valid-tab lists (the initial `tab` check and the `hashchange` handler). Users choose which tabs sit in the bottom bar in Settings; the rest go under More.
- **Stretch routine:** "Start routine" runs every step with a tone (Web Audio, unlocked by the tap) and a short rest between steps, keeps the screen awake where supported, and marks the day done at the end. Its timer (`rtI`) survives `render()`; leaving the tab stops it.
- **Groceries** remember past items in `S.gHist` for Quick add.
- **Daily rotation:** word, quote and stretch step use `dayNum()`; weekly topics use `weekNum()`. One vocab word per day, followed by a one-question check.
- **Design:** warm, editorial look by default (serif type, paper tones). Skins are `parchment`, `quest`, `forest`, `arena`, `pixel`. Keep dark mode high-contrast; the owner asked for more contrast there. Keep Today uncluttered: appearance and backup live in Settings.
- **XP, levels and badges were removed on purpose** (Nov 2026). Each habit still shows its own day streak. Old saved fields (`lastLevel`, `game`, `wc`) are left in place so older backups still load.
- **Fantasy football was removed on purpose.** The owner is building it as a separate project. Do not re-add it here.

## Refreshing the news
The brief is normally generated by the daily GitHub Action (`scripts/refresh-news.js`, feeds in `scripts/news-sources.json`, provider `claude-code` with secret `CLAUDE_CODE_OAUTH_TOKEN` from a Claude subscription, or provider `api` with secret `ANTHROPIC_API_KEY`; set `provider` in `news-sources.json` or `NEWS_PROVIDER`). The prompt rules live in `SYSTEM` in that script (`SYSTEM_CLI` is the same text for the CLI path) and mirror the rules below. A manual refresh is overwritten by the next scheduled run. Run `npm test` after touching `scripts/`. Subscription runs use the owner's Claude usage; API runs cost a small amount of API money. The model comes from `news-sources.json` or `ANTHROPIC_MODEL`.

Manual refresh:
When asked to "refresh the news", replace `js/data/news.js` with a new `NEWS` object, then run `npm run check`.
```js
const NEWS = {
  date: "YYYY-MM-DD",            // today; the News tab says "needs refresh" when this is not today
  label: "Tuesday, Nov 24",
  tip: "...",                    // short reading tip
  also: ["one-line item", ...],  // "Also noted"
  items: [{
    r: "US" | "W",               // United States or World section
    h: "Headline",
    w: "What happened, 2 to 3 sentences",
    y: "Why it matters, one sentence",
    p: "Who's saying what, or \"\" if not politically charged",
    s: ["Source", "Source"]
  }]
};
```
Rules the owner asked for: a quick read of about 3 minutes covering American and global news, with as little political bias as possible and a clear note when a source leans one way.
- Paraphrase. Do not copy article text. Name every source.
- For politically charged stories, use `p` to show each side's framing with attribution, not a verdict.
- Flag single-source stories and anything unverified (for example, claims by one party to a conflict).
- Take election results and calls from the AP, and include the "as of" time.
- Aim for 5 to 6 stories, roughly 3 US and 3 world.

## Content
- **Words:** append to `WORDS` as `[word, partOfSpeech, definition, example]`, then add its index to one of the `LEVELS` lists. The owner wants the word lists tuned to their level; ask which words feel too easy or too hard.
- **Quotes:** the owner reads James Clear's weekly emails and may paste quotes in. Check attribution before adding (for example, "We are what we repeatedly do" is Will Durant summarizing Aristotle, not Aristotle).
- **Topics:** seven rotating weekly topics (AI, tech sales, history, leadership, communication, relationships, finance), five short lessons each, each with one multiple-choice check. Answer order is shuffled per lesson and week (`order()`), so the correct index in the data can be anywhere. Finance lessons are general education, not advice.
